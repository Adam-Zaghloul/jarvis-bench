# Board 10000000000011 — status LED never blinks → R14 open

**Board / rev:** DEMO-1 rev A
**Date:** 2026-02-03
**Status:** RESOLVED

## Symptom
Power on, rails present, status LED D1 never lights.

## Measurements
- 3V3 at C30: 3.31 V
- U3 pin 15 (LED_STATUS): 1 Hz square wave, 0 to 3.3 V
- R14 (power off): open circuit, expected 330 Ω

## Root cause
R14 open. The MCU drove the pin correctly; no current reached D1.

## Fix
Replaced R14 (330 Ω). LED blinks at 1 Hz.
